# Landing Page

A landing page created as part of **The Odin Project – Foundations** curriculum.

## About

This project focuses on practicing the fundamentals of **HTML and CSS**, with an emphasis on using **Flexbox** to create and organize page layouts.

## Built With

- HTML5
- CSS3
- Flexbox

## Features

- Responsive page layout
- Header and navigation
- Hero section
- Information cards
- Quote section
- Call-to-action section
- Footer

## What I Learned

Through this project, I practiced:

- Structuring webpages with HTML
- Styling elements with CSS
- Using Flexbox for layouts
- Working with colors, fonts, spacing, and alignment
- Organizing a webpage into different sections
